Simple Voice / 轻音输入法 0.2.0-rc.4

1. 将整个压缩包解压到长期保留的文件夹。不要在 ZIP 中直接运行。
2. 如果没有安装 Microsoft Visual C++ x64 运行库，请先安装：
   https://aka.ms/vc14/vc_redist.x64.exe
3. 双击 install.cmd。首次下载官方运行时和模型并校验，随后申请管理员注册。
4. 注销 Windows 后重新登录，Win + Space 选择「轻音输入法」。
5. Ctrl + Alt + Space 开始语音；停顿后校准并预览，Enter 写入，Esc 取消。
6. 浮层右键可编辑预览、复制或恢复识别原文。设置可选择麦克风、停顿与语音模型。

check.cmd：准备依赖并加载模型自检，不开麦、不注册、不读取个人词库。
uninstall.cmd：取消注册；注销再登录后可删除程序文件夹，个人词库默认保留。

安装后请不要移动本文件夹。更新时使用新目录，注册后注销再登录。
模型下载完成后可以离线使用。当前仅 Windows Intel/AMD x64。
建议16GB内存、8GB可用磁盘（含首次下载解压缓存）。
这是未签名的发布候选；真人麦克风与浏览器/Codex 场景仍待现场验收。
