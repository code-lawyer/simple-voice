# Simple Voice 专业发行改进：统一产品、开发与测试计划

历史计划（v0.2.0-rc.1 阶段）。现行方案和剩余发行门槛见 [当前冲刺计划](public-release-sprint.md) 与 [PRODUCT](../../PRODUCT.md)。

基线：v0.1.0 / 065b6c7。用户于 2026-11-15 授权按系统调研统一实施；本计划先于产品改动建立，实施证据另记。目标为 Windows x64 发布候选版本；真人麦克风和用户应用现场验收继续后置，不以自动化通过冒充正式版验收。

## 产品方案

核心承诺：中文、英语和混合输入开箱可用；用户确认的是最终将写入的文本；个人偏好帮助选词，不擅自改写正确内容。沿用 TSF、C++/Win32、本地 sherpa 和 Rime，保留钛银/极昼/深空、无账号、不上传/保存录音、按需开麦和最终预览确认。

1. **基础输入**：全拼、简拼、常见错拼、现代中文词组、英语前缀补全及中英候选竞争。空格选词，Enter 保留原始英文/拼音字符串；组合内方向键、删除、候选导航、Ctrl+Delete 遗忘有确定含义。模糊音默认克制，不扩大为自动上屏。新数据有固定来源、授权和校验。
2. **后台使用偏好**：拼音沿用 Rime 学习，可暂停或遗忘；语音整句确认不再把全部分词作为个人术语，也不再保存新的待学习整句。旧记录保留可恢复性并继续按原 365 天清理，永远不作为强制改写依据。
3. **我的词语/常用语**：用户明确添加、编辑、搜索、移除与撤销。文字与输入码可查看，普通统计不混入此列表。明确术语用于可选候选；仅模型原生支持时才可作为有边界的词表提示，禁止后置无上下文同音硬替换。沿用 365 天未使用期限，不擅自新增永久保留。
4. **语音**：同机对比现有 CTC、SenseVoice、Qwen3-ASR 与中英流式模型；依据同组中文、英语、混说、短词测试选择。分开记录草稿、原始定稿、格式整理；未知输出不能伪装成功。允许编辑待确认文本、恢复识别原文、复制当前文本，再确认写入；明确保存词语需要用户动作。
5. **可靠性与准备**：先展示程序/模型准备状态，再允许录音；首帧采样才显示“正在听”；设备选择、输入电平、无设备/权限/全零/无词/断连提示和重试。失败保留当前文字，不盲目重发。用户能检查模型准备与版本，不记录诊断正文和音频。借鉴 Handy 的机制，不迁移其录音持久历史。
6. **统一设置**：原生可键盘操作的设置窗口，任务分区为输入、我的词语、语音与诊断。空态、无匹配、校验失败、保存失败、模型准备和设备错误均有可执行下一步；颜色/字体延用 DESIGN.md，高对比与 DPI 优先。
7. **分发维护**：可复现构建、Windows CI、独立安装包、自检、固定依赖哈希、清楚的更新/回滚/卸载说明和兼容范围。开发不覆盖已安装目录；未经单独发布指令不推送公开 Release。

## 开发顺序与责任边界

| 阶段 | 工作 | 完成证据 |
|---|---|---|
| P0 | 保留 ASR 原文；去掉不安全替换/自动收词；旧记录兼容；关键数据保护测试 | 时间/实践、10/20、Claude/Codex 等回归均不误改 |
| P1 | 词库 API、显式术语管理、撤销/搜索/期限、跨输入候选适配 | 迁移/删除/重启/无私文日志/大词量测试 |
| P2 | 已核验基础词表、简拼/错拼、英文候选、TSF按键与组合编辑 | 固定候选质量集、真实 TSF 宿主及原有回归 |
| P3 | 隔离模型下载与同机横评；按结果接入默认组合和下载清单 | 可复现的逐样本文本、耗时、内存、来源哈希 |
| P4 | 模型准备/重试、真实采音就绪、设备/电平/错误恢复、预览编辑与复制 | 注入故障、快速取消/重入、无采样/静音/失联测试 |
| P5 | 原生设置/词语管理、可跳过使用引导、三皮肤与高对比/DPI审查 | 原生截图、键盘/可访问性/边界状态测试 |
| P6 | 全回归、包验证、CI、文档及已知限制 | 统一验证报告、可检查安装产物与哈希 |

模型和词表研究可并行在隔离目录进行；生产修改按依赖顺序整合。选择结果由数据决定，发现质量不够时继续调整，不以研究完成代替功能完成。

## 测试计划与质量门槛

- **文本安全（硬门槛）**：所有已复现错误改写与扩展的数字/日期/金额/英文/标识符用例零误改；确认文本与实际提交字符串逐字相等；失败和重复确认不重复上屏。
- **词库**：空库/旧库/损坏与锁定；显式加入与编辑去重；大小写与 Unicode；搜索和删除撤销；365天边界；普通语音不会创建词条；大量使用不产生完整语音历史；大词量查询有界。
- **拼音**：分开测试全拼/简拼/错拼/模糊音；常见现代词及长句的首选、前5命中；英语单词/短语/缩写；不把成功拼成任意汉字视为通过。按键、大小写、组合内编辑、Esc、Enter/空格、数字/鼠标选词、遗忘分别回归。
- **语音选型**：中文基线3段、公开中英混说、英语短词与整句、数字与术语；每模型同机相同线程设置，重复至少3次；报告冷启动、原始文本、错误率/关键词保留、定稿等待、峰值内存。合成音频只用于定位，不替代自然语音与真人验收。
- **状态与故障**：准备中不能误开录；无首帧超时、全零、无词、设备断连、模型缺失、加载失败、快速取消、迟到回调、写入断线与超时；当前文本可恢复/复制。
- **原生 UI**：三皮肤、100/150/200% DPI、高对比、长词/长句、空态、错误态、键盘操作、焦点和候选不闪烁；按 impeccable 做一次集中审查与必要修正后的确认。
- **集成**：既有 unit/engine/TSF/popup CTest 全通过；新增模型与词表质量集；线程及资源释放、真实TSF隔离宿主；浏览器/Codex现场和真人麦克风列为待验，不写成已通过。
- **包与升级**：新目录构建/解压可独立启动、自检通过；依赖固定哈希；不引用开发目录；旧词库和设置可迁移；注册/更新需另按已授权部署范围处理。

## 发布判断

自动化和模型样本通过后交付发布候选及完整证据。正式版仍需真人麦克风、浏览器/Codex现场、支持的Windows环境与发行签名/可信发布流程验证；签名身份等外部资产缺失如实记录，不生成虚假“可信发布者”。不把尚未测试的32位应用、ARM64、多平台或全部开源竞品功能宣称为支持。
