# Voice IME Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Windows 上做出一个纯语音的系统输入法：快捷键开麦，字先出现在光标旁的框里，回车才进文档，上屏过的习惯词自动留下来。

**Architecture:** 逻辑（词库、静音、会话状态、摆放）放在可单测的库里。一个常驻 `voiceime_engine.exe` 负责采音、识别和确认框。一个很薄的 TSF 文本服务只在「本输入法正在当前文本框里」时接收快捷键，并用选区插入最终文字。未确认的字不写进目标程序。

**Tech Stack:** C++17、CMake、MSVC、SQLite amalgamation 3.46.1、cppjieba、sherpa-onnx v2.0.1 Windows x64 shared MD Release（CPU，不要 CUDA）、Win32、TSF。

**Spec:** `docs/superpowers/specs/2026-11-13-voice-ime-design.md`

## Global Constraints

- 只有语音。没有拼音键盘，没有候选条。
- 确认框贴着光标；未按回车前，文档里没有这段字。不用剪贴板，不模拟按键。
- 默认快捷键 Ctrl+Alt+Space，可改。Esc 清空。快捷键只在本输入法是当前输入法且存在可插入文本的焦点时生效。
- 按一次快捷键就开麦，说话时不用按着。停口约 500 毫秒进入定稿。一段最长 60 秒。
- 音频 16 kHz、单声道、16 bit，只在内存里，不写文件。
- 回车时如果定稿还没完成，等定稿和标点，插入定稿，不插入流式草稿。
- 词：2 到 8 个 Unicode 码点，上屏次数加 1。单字不记。次数为 1 只保存，不改变识别。次数至少为 2 且拼音相同才替换。
- 整句第一次上屏不入库。同一句再次原样上屏才记为 phrase。
- 超过 180 天未再上屏的条目不参与替换。超过 365 天删除。
- 清空、未回车，不写词库。不保存音频。
- 流式模型 `sherpa-onnx-streaming-zipformer-ctc-zh-int8-2025-06-30`。定稿 `sherpa-onnx-zipformer-ctc-zh-int8-2025-07-03`。标点 `sherpa-onnx-punct-ct-transformer-zh-en-vocab272727-2024-04-12-int8`。
- 默认不加载 SenseVoice、Paraformer、Whisper、Qwen、FireRed。
- 代码 Apache-2.0。不链接 GPL，不附带微信输入法的文件。仅 CPU。建议 8 GB 内存。
- 数据目录 `%LOCALAPPDATA%\VoiceIme\`。产品名 `VoiceIme`，引擎 `voiceime_engine.exe`，文本服务 `voiceime_tsf.dll`。

## Review Focus

这五类输入最容易在真实使用里出错，单测必须钉住：

1. 定稿还在算时按回车，插入的是定稿而不是草稿。钉在 Task 5 `SessionKeepsDraftUntilFinalThenEnterCommitsFinal`。
2. Esc，以及待确认时再按快捷键重说，都不写词库、都不插入。钉在 Task 5 `EscapeAndRestartDoNotCommit`。
3. 只上屏一次的整句，不能把下一句整段换掉；次数为 1 的词不能替换。钉在 Task 2 `FirstSentenceAndSingleCountDoNotReplace`。
4. 超过 180 天的词不再替换，超过 365 天被删掉。钉在 Task 2 `ExpiredEntriesDropOut`。
5. 拿不到光标矩形时，框落到窗口客户区右下角，且这个决定不包含「写入文档」。钉在 Task 6 `MissingCaretGoesToBottomRight`。

**Interfaces:**
- Consumes: `Token`、`CodePointCount`

```cpp
class Lexicon {
 public:
  explicit Lexicon(const std::string& db_path);
  void Commit(const std::string& full_text, const std::vector<Token>& tokens, std::int64_t now_unix);
  std::string Apply(const std::string& recognized, const std::vector<Token>& tokens, std::int64_t now_unix);
  std::vector<Entry> Recent(int limit);
  bool Delete(const std::string& text);
};
```

SQLite amalgamation 3.46.1 放进 `third_party/sqlite/`（`sqlite3.c`、`sqlite3.h`），由 CMake 编进 `voiceime_core`。不要用系统里别的 SQLite。

规则：

- `Commit` 开头按 `now_unix` 删掉 `last_commit_unix` 早于 365 天的行。
- token 的码点数在 2 到 8 之间才作为 `word` 加 1。同一个 `text` 已存在则 `count` 加 1 并更新时间。第一次 count 为 1。
- 码点大于 8 的整句不进 `entries` 的第一次记录。用只在内部存在的表 `seen_phrase(text TEXT PRIMARY KEY)` 记住见过一次。`Recent` 不返回它，`Apply` 不用它。第二次原样 `Commit` 时插入 `kind=phrase`、`count=2`，并删掉 `seen_phrase`。之后再原样提交则 `count` 加 1。码点在 2 到 8 的整句只走 word 规则。
- `Apply` 不使用 `count < 2` 的行。`now_unix - last_commit_unix` 大于 `180 * 86400` 的行不参与替换。
- 若 `recognized` 的各 token 拼音用空格拼起来，与某条 phrase 的 `pinyin` 完全相同，替换整段为该 phrase 的 `text`，然后返回。多条时取 `count` 最大，再取 `last_commit_unix` 最大。
- 否则逐个 token：拼音相同的 word 里按同样的排序取一条，文本不同就换掉这个 token。token 之间直接拼接，不加空格。
- 拼音比较是完整字符串相等，大小写敏感。调用方保证拼音无声调、小写、音节之间一个空格。

struct VadConfig { int sample_rate; int silence_ms; int max_utterance_ms; int speech_rms; };

**Interfaces:**
- Consumes: `Phase`
- Produces:

```cpp
class Session {
 public:
  Phase phase() const;
  bool mic_open() const;
  const std::string& box_text() const;
  void Hotkey();
  void OnDraft(std::string text);
  void OnSpeechEnded();
  void OnFinal(std::string punctuated);
  void Enter();
  void Escape();
  bool TakeCommit(std::string* text);
  bool TakeLexiconWrite(std::string* text);
};
```

- Idle 时 `Hotkey` → Listening，麦开，框空。
- Listening 时 `OnDraft` 只改框内文字。`OnSpeechEnded` 或再次 `Hotkey` → Finalizing，麦关。Finalizing 期间再来的 `Hotkey` 忽略。
- `OnFinal` 在 Finalizing：若已经按过回车，直接进入可取走的提交，框清空，阶段 Idle，麦关。没按过回车则 Pending，框改为定稿文本。
- Pending 时回车：提交框内文字。Esc：不提交。Hotkey：丢掉框，回到 Listening，麦开。
- Listening 或 Finalizing 时 Esc：回 Idle，不提交。
- `TakeCommit` 和 `TakeLexiconWrite` 只在真正提交时各返回 true 一次，文本相同，且是定稿不是草稿。Idle 时 `Enter` 无效果。

`PlaceBox`：光标矩形宽高都大于 0 时，框的左上角放在光标正下方，左边与光标对齐。否则框的右下角贴着窗口客户区右下角，留 `margin` 像素。`margin` 使用 16。

`Encode`/`Decode`：`uint32` 小端长度（含 type 字节和正文）+ `uint8` type + UTF-8 正文。`SetHotkey` 的正文是 `key_mod` 和 `key_vk` 两个 `uint32` 小端，不另带文字。半包 `Decode` 返回 false 且 `consumed` 为 0。`DefaultHotkey()` 返回 modifiers `1|2`、vk `0x20`。
