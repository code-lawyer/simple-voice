## Standards

1. **P1：模型生命周期竞争。** 录音中修改中文优先设置，随后用语音热键停止时，原分支会先处理模型不一致，卸载仍被采音线程使用的识别器。修复为先处理 Listening / Finalizing / Committing，再考虑下一段的模型切换；BeginPrepare 也拒绝活动采音或定稿线程。
2. **P2：个人词码校验与键盘可达性不一致。** 保存允许数字，但数字按键属于候选选择。现统一仅小写英文字母，生成器和提示同步；数字/大写/制表符输入码被拒绝。
3. **P2：输入法自己的编辑框被语音状态抢占。** 全局待确认语音状态导致编辑器中文选词、Enter 路由错误。现按焦点根窗口识别自己的设置/预览编辑器，关闭其语音键拦截，保留正常拼音输入。

## Spec

1. **P1：模型选择不能改变当前录音。** 计划要求设置只作用于后续录音。已按上述生命周期修复，并验证当前草稿能正常定稿，下一段才切换。
2. **P2：输入码保存后必须可用。** 数字码违背“明确术语用于候选”的可达承诺。现限制为实际支持的小写字母，完整保留文字中的数字。
3. **P2：标点整理仍可合并信息。** 原字符比较无法发现 `10 20 → 1020` 或 `a part → apart`。现除内容字符外比较有序 ASCII 词元，并保留数字/标识符内部标点；变化则回退原识别。
4. **P2：语音校准编辑器必须能正常输入中文。** 对应上述自己的窗口路由修复；不是只改 UI 提示。

## 修复证据与范围

- `tools/engine_integration.cpp` 实际运行生产引擎测试宿主：录音中保存模型选择、热键停录保留结果、下段启用新配置、慢定稿取消响应、迟到结果隔离；另测加载中取消、加载失败、重试成功。
- `tools/tsf_integration.cpp` 使用真实 TSF 管理器和隔离文本存储，在语音激活状态下模拟本产品原生编辑窗口，中文组合/选词/Enter 行为通过。
- `tests/text_safety_test.cpp` 增加上述分词合并、数字日期/标识符、非法输入码，以及10,000条词语的容量、分页和满库编辑检查。
- 全套构建与最终回归见 [发行验证报告](../releases/v0.2.0-rc.1-validation.md)。没有把主任务回归称为两个审查者对修复后代码的独立二次认证。
