## 已持久化的系统扩展

规则同步写入 [DESIGN.md](../../DESIGN.md) 与 [.impeccable/design.json](../../.impeccable/design.json)。既有调色板、圆角、浮层字体和尺寸 token 保留；新增内容来自 [preferences_window.cpp](../../src/preferences_window.cpp)、[preferences_window.hpp](../../src/preferences_window.hpp)、[ui_theme.hpp](../../src/ui_theme.hpp)，并对照 [confirm_box.cpp](../../src/confirm_box.cpp) 和 [candidate_bar.cpp](../../src/candidate_bar.cpp) 的既有行为。

- 设置采用钛银背景和正文色，系统高对比度优先；按钮、标签页、列表、输入框沿用 Windows 控件状态。输入浮层继续按所选皮肤绘制。
- 字体仍为 Microsoft YaHei UI：新增设置标题 23 DIP / 半粗体、设置控件 14 DIP / 常规、预览编辑器 15 DIP / 常规。没有替换原有浮层字体层级。
- 设置目标客户区为 680 × 690 DIP，受工作区约束；高度不足时整页滚动，Tab 导航保持焦点控件可见，Ctrl + Tab 切页，Esc 关闭。底部动作按标签页区分。
- 词语空库与搜索无结果使用不同文本；结果范围与词库总数分开说明。读取失败、保存失败和部分保存成功在状态区明确呈现，不改成成功状态。
- 预览编辑器是可激活、可调整尺寸的原生工作窗口。Enter 在正文中换行，Ctrl + Enter 保存待确认预览，Esc 取消编辑；恢复原文、复制、保存分别反馈。保存预览后仍需用户确认写入宿主。
- Sidecar 记录原生组件元数据、键盘、滚动、错误与证据边界，不生成 HTML/CSS 假组件，不把 Windows 控件运行时颜色伪装为固定皮肤 token。

## 验证边界

`preferences-bottom-dpi-192.png` 是合成消息驱动的**客户区**截图，不包含 DWM 非客户区，也未证明物理显示器间移动、真实系统缩放切换或窗口框正确。测试里的高对比度通过注入分支检查，不能替代用户启用系统高对比度后的整体验收。
