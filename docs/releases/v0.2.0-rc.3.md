# v0.2.0-rc.3 · 声核标识

Windows x64 本地发布候选，继承 [rc.2](v0.2.0-rc.2.md) 的修复。

- 内置用户选定的 A「声核」标识，提供 Windows 原生多尺寸图标。
- TSF 注册品牌图标和系统托盘能力，接入系统输入模式按钮，悬停显示“轻音输入法 · Simple Voice”。
- 「中 / A」与 Shift 和按钮点击保持一致；只读输入框禁止切换，输入法停用后移除按钮并解除回调。
- 引擎托盘替换默认系统应用图标；系统主题、显示缩放及 Explorer 重建任务栏后刷新标识。
- 安装改用 Windows 官方 profile/category API 并迁移旧注册记录；校验提权账号，避免更新了另一用户的配置却报告成功。

模型、词库、语音确认流程和三套皮肤沿用 rc.2。新版本独立安装，保留旧版本与个人数据。真人语音验收待完成，公开安装包以 [GitHub Releases](https://github.com/code-lawyer/simple-voice/releases) 上的附件为准。
