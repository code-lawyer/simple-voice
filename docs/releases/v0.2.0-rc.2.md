# v0.2.0-rc.2 · 审查问题修复

Windows x64 本地发布候选。继承 rc.1 的双语语音、拼音数据、三层词库与三套皮肤，本轮修复独立代码审查确认的五项问题。

- 拼音组合移动光标或删除字符后，Enter 提交完整的编辑后原始输入，不丢失光标后面的文字。
- `#include`、`#@metadata` 等以井号开头的个人词语可正常成为候选，保存和重新启动后保持有效。
- 新一段语音请求立即关闭旧预览编辑器；保存回调核对录音轮次，不能覆盖正在准备的新录音。
- 写入回执超时后，保存或修改预览仍保留“写入结果待核实”，编辑窗口也提醒先检查正文。
- 预览编辑器支持 Tab / Shift+Tab 遍历正文和按钮，Ctrl+Enter 保存，Esc 取消。

按用户授权安装到新的版本目录。个人目录和 TSF 标识保持兼容；更新前备份个人数据，保留旧安装目录。已经加载旧输入法 DLL 的应用需要完全退出重开；若系统仍使用旧模块，注销后重新登录。

本轮不公开推送 Release。真人麦克风、浏览器/Codex 实际体验由用户随后测试；未代码签名、兼容范围和模型识别边界不因这些修复而改变。详见 [验证记录](v0.2.0-rc.2-validation.md)。
