# v0.2.0-rc.9 · 模型闲置释放设置修复

「本地模型」中的「闲置 5 分钟后释放模型」现在点击即保存并生效。重新打开设置、重启轻音或切换模型后，仍会保留最近一次选择。

默认开启。关闭后，已经加载的模型会在闲置期间保留。首次运行或模型已释放时，仍会在需要时加载模型。

从旧版升级时，将完整 ZIP 解压到新的目录，再运行 `install.cmd`。按提示注销 Windows 并重新登录，使已打开的应用加载新版输入法。个人数据沿用原有用户目录。

这是 Windows Intel/AMD x64 的未签名发布候选。ZIP 随附 SHA-256 校验文件。 [验证记录](v0.2.0-rc.9-validation.md)
