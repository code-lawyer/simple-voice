# v0.2.0-rc.6

本轮将模型选择收敛为三个固定方案，并补齐取消、故障恢复、备份和升级检查。此候选仍未签名，按预发行版本提供。

## 用户可见变化

- 设置 → 本地模型：Qwen3-ASR（推荐）、SenseVoiceSmall（轻量）、Whisper Turbo（多语言）。选择并启用即可；下载完成校验，隔离试加载成功后保存选择。旧中文方案保留已有配置兼容。
- 可使用对应型号的现成 ONNX 文件夹。原始 PyTorch / Safetensors、whisper.cpp 的 GGML 文件，以及其他任意架构不属于此导入入口；无需用户手动转换默认下载包。
- 失败不破坏当前可用模型。录音或预览中更换模型，在下次录音前验证；默认闲置 5 分钟释放模型内存。Qwen3 的常用专名由用户明确填写，不自动收集语音内容。
- 模型页只保留一个启用主操作，明确显示当前模型，下载与验证期间保留取消；完整保留同次设置的专名和闲置选项。长错误和备份路径可以选择、复制、滚动阅读，键盘 Tab 可离开只读输出框。
- 模型在子进程运行，取消可终止计算，加载崩溃或超时不会拖垮主界面。长段语音在录音时提前校准完整片段。
- 使用诊断中可主动练习录音、预览和确认；确认结果仅出现在设置页。
- 备份恢复包含手动保存词语、输入设置、快捷键与外观；校验损坏，恢复前备份，写入失败回滚，中断后在下次启动恢复旧数据。不包含 Rime 自动学习统计、模型、模型选择或录音。
- 升级检查报告旧引擎和已加载 DLL；退出码 3010 表示注册已完成、需要注销 Windows。未来旧 TSF 不再启动与当前注册目录不一致的引擎。早期 rc.3 等已加载代码仍需注销后清理。

## 安装与回滚

完整解压 ZIP 到新目录，运行 install.cmd，按提示完成注册，然后保存工作、注销并重新登录。不要覆盖旧目录或只反复结束旧引擎进程。保留旧目录可回滚，回滚前备份词语与设置，重新运行旧目录安装程序并注销登录。

包不含模型权重；按需从固定官方 URL 下载并校验 SHA-256。SenseVoice 权重采用自定义 FunASR Model License，许可证见第三方说明。散列用于校验文件损坏，不能代替可信发行签名。
