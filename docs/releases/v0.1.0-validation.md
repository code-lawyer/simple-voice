# v0.1.0 发布验证

验证日期：2026-11-15。Windows 11 x64，WinLibs GCC 16.2.0 / MinGW-w64 UCRT POSIX，
CMake Release 构建；静态 Rime 依赖复用已构建的 1.17.0 前缀。

| 检查 | 结果 |
| --- | --- |
| 单元与并发测试 | 82 项通过 |
| 隔离引擎 IPC 集成 | 298 项通过；模拟采音，不连接已安装输入法 |
| Windows TSF 文本存储集成 | 64 项通过，调用真实 Windows TSF 接口 |
| 原生浮层稳定性 | 三套皮肤通过；重复相同更新不移动、不重画、不重复显示 |
| CTest 汇总 | 4/4 通过，约 30 秒 |
| 真实语音模型 | 三段上游 WAV 通过，覆盖 16 kHz 与 8 kHz 输入；最终文字先预览，确认后原样写入 |
| 词库异常回退 | 通过；词库异常时保留识别结果并提示 |
| 官方依赖下载 | 全新目录下载 SDK 与三个模型，归档及必需文件 SHA-256 全部一致 |
| 安装包独立性 | ZIP 解压到含中文和空格的目录，校验逐文件清单；脱离源码工作目录加载全部模型和字典 |
| 工作目录干扰 | 工作目录放置同名无效模型/字典时，优先使用安装目录的有效资源 |
| 缺少模型 | 安装自检返回失败码 2，不误报就绪 |
| 下载故障保护 | 损坏缓存被拒绝，已有文件保留；依赖目标不能越出安装目录 |
| 卸载保护 | 其他目录的包拒绝卸载当前安装版，在管理员提示之前退出，注册保持不变 |
| 版本信息 | 引擎、注册程序和 TSF DLL 均显示 Simple Voice 0.1.0 / Preview |
| 公开内容检查 | 历史 321 个 Git blob 完成常见凭据格式扫描，无命中；发布采用文件清单，排除个人数据、模型和本机审查日志 |

模型样本推理及定稿约 0.46–0.67 秒/段；样本长度约 4.5–5.6 秒。
该次识别进程工作集约 958 MiB。这些是本机样本测试数据，不代表所有电脑的性能。
