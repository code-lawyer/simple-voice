# v0.2.0-rc.10 · 本机语音试用版

切入轻音时可自动准备语音模型。按下语音键后立即开始收音，双语草稿模型就绪便开始显示口述内容。Qwen3-ASR 在后台准备，即使先说完，也会用完整录音校准定稿。

普通话开头可通过共享模型权重的临时识别流提前显示第一个汉字。浮层在草稿变化时更新。Qwen 每次定稿后会释放此次推理用过的临时内存，继续使用原来的词表、模型权重、热词和闲置释放设置。

试用时按 Win + Space 选择「轻音输入法」，在输入框里按自己的语音快捷键开始说话，按 Enter 停录校准，再按一次 Enter 写入。首次安装的默认快捷键为 Ctrl + Alt + Space，升级会沿用已设定的组合键。设置页「使用与诊断」也可以试录。

从旧版升级请将整个包解压到新的固定目录，运行 `install.cmd`。已经打开的应用可能仍加载旧版 DLL，保存工作并注销、重新登录后即可全部切换。此包为 Windows x64 未签名试用构建，附 SHA-256。具体延迟、内存与测试边界见验收记录。[本机实测](v0.2.0-rc.10-validation.md)
