# v0.2.0-rc.5 · 本地语音控制与快捷键

- 语音引擎核验 Windows 登录会话、输入法宿主及当前前台应用。过期的确认操作无法提交后来产生的预览。切换到另一应用后，仍可确认写入当前预览。
- 输入法加载时缓存快捷键。在设置中成功保存新快捷键后，已运行的输入法会重新读取。打字和按键预检直接使用缓存。
- 清理已退出生产流程的词库接口和协议类型。显式词语、旧记录的迁移及保留期限沿用现有规则。

这是未签名的 Windows Intel/AMD x64 发布候选。将 `SimpleVoice-v0.2.0-rc.5-windows-x64.zip` 完整解压到新目录，运行 `install.cmd`，授权注册后注销 Windows 再登录。安装时会准备并校验本地运行时和语音模型。已有安装目录可用于回滚。

新版引擎和输入法 DLL 需要成套升级。进程级校验依赖受信任的桌面宿主，其保护范围及升级要求见[本地 IPC 约定](../ipc-security.md)。[自动回归及验收范围](v0.2.0-rc.5-validation.md)。
