# v0.2.0-rc.5 验证记录

使用 Windows x64、WinLibs GCC 16.2.0、CMake 和 Ninja 在新目录构建 Release。引擎、TSF DLL 和注册工具均标记为 `0.2.0-rc.5`。

| 验证 | 结果 |
| --- | --- |
| CTest | 4/4 通过，67.42 秒。含 88 个单元测试、853 项隔离引擎检查、124 项真实 TSF 检查和浮层回归。 |
| 原生控件 | 钛银、极昼、深空各 66 项检查通过。 |
| 真实语音模型 | 三段固定 WAV 样本离线识别通过，含 8 kHz 输入。预览文本在确认前不写入，确认后逐字保留。 |

IPC 回归覆盖未授权连接、借用其他进程窗口、错误消息方向、后台操作、过期话轮及跨应用确认。快捷键回归覆盖配置文件独占时的读取和保存通知。词库回归覆盖迁移、365 天过期及同音词、数字和英文名称的原样写入。

引擎集成使用真实管道与进程，采音和前台进程为测试夹具。真实 TSF 测试使用隔离宿主。真人麦克风、浏览器/Codex 编辑和跨权限宿主仍需现场验收。协议与部署约定见[本地 IPC 约定](../ipc-security.md)。
