# v0.2.0-rc.7 验证记录

2026-11-17，本机 Windows x64、MinGW GCC 16.2.0，独立构建目录 `build-review/manual-stop`。本记录描述本地源码、候选包及测试证据；不代表已公开发布或已经替换系统注册的旧版本。

## 问题与回归闭环

旧版使用固定 RMS 800 的停顿判断，低音量连续发声可能被当成静音。此前最小复现中连续发声在 1.2 秒进入校准；项目自带的 5.15 秒语音在音量缩到四分之一后于 2.10 秒触发端点。

本次先新增真实引擎路径的断言：保留旧 `pause=500` 配置，合成“讲话后停顿”并要求继续收音。旧实现下运行 `voiceime_engine_integration.exe <隔离目录> --manual-stop-only`，失败于 `silence, quiet speech and more than 60 seconds never finalize before manual stop`；完成修改后同一路径通过。

生产与测试宿主共用 `AcceptCaptureAudio`、采音健康判断和样本计数边界，测试只替换设备输入及识别器，不跳过停录策略。

## 自动回归

- 独立 Release 构建通过。
- CTest 五组最终均通过：单元/并发、真实引擎 IPC、真实 Windows TSF 隔离宿主、浮层回归、模型子进程故障恢复。
- 首次整套运行前四组通过；新增模型长度用例一次性提交十分钟数据，超过既有单次传输大小限制。将测试改为真实采音使用的分包方式后，模型组单独复测通过，7 个 worker 场景通过。此调整仅涉及测试输入组织，没有放宽传输限制。
- 手动流程的定向测试共 92 项检查通过：讲话后长停顿、先响后轻、超过 60 秒、持续静音、第一次确认只校准、第二次确认精确写入预览、10 分钟上限、到时与手动停止竞态、旧确认请求拒绝、快捷键定稿、取消、重新开始及设置页试用。
- TSF 新增检查覆盖录音中和到时待校准两种起点，模拟 Enter 自动重复跨越校准/预览阶段；重复按键不会发送确认，新按下的 Enter 使用新预览状态序号。
- 单元回归覆盖到时保留草稿、等待手动校准、尾包裁剪、长度整数溢出、IPC 新阶段 5 与非法阶段拒绝。持续静音及低音量只提示；真正停止返回采样仍报告错误。
- worker 经真实私有管道接收超过旧 61 秒边界的音频，重置后接收完整十分钟分包，再拒绝多出的一个采样，并可新建 worker。

CTest 需要普通桌面用户令牌以满足现有 IPC/TSF 身份校验；受限令牌下连接失败不是语音行为复现。测试未降低身份检查，未打开麦克风、修改系统注册或访问个人词库。

## 模型样本与界面

默认 Qwen3-ASR 使用真实隔离 worker 完成 3 个样本检查：5.61 秒上游中文样本、同一样本拼接的 65 秒语音、12 秒静音。语音得到非空最终文字，校准预览与确认提交一致；静音返回空文本。65 秒样本停录后定稿耗时单次观测约 6.83 秒，worker 峰值工作集约 2219.6 MiB。重复语料仅验证长度和流程，不能当作十分钟真人听写准确率验收。

三套皮肤的原生 UI 检查全部通过。截图人工检查了设置页两次确认说明、超过一分钟的计时、最后 30 秒提醒、达到上限后的等待提示；无文字遮挡。UI 截图和日志在 `build-review/manual-stop/ui-*`，模型日志为 `build-review/manual-stop/model-smoke.log`。

## 范围与部署

移除旧停顿检测器；旧 `preferences.ini` 与备份中的停顿字段继续读写兼容，不再参与收音。最大长度统一由采音端、模型进程和识别器共用，避免仅延长界面上限却仍在 worker 的 61 秒限制处失败。

新增阶段值 `5` 表示“到上限，已停录但待手动校准”，必须整体升级 DLL、引擎和 worker。Windows 中已加载旧 DLL 的应用需要注销再登录刷新。当前未执行生产注册或替换已安装版本。

真人麦克风、用户实际编辑器、十分钟连续真人语音及全部可选模型本轮未现场验证；本轮真实模型检查为 Qwen3-ASR。未签名，未公开发布。
