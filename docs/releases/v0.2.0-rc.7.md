# v0.2.0-rc.7

语音改为手动停录、校准后再次确认写入，解决停顿或讲话变轻时被自动结束的问题。本轮为本地构建的发布候选；公开发布状态以 GitHub Release 为准。

## 使用变化

- 录音中按 Enter 或再次按语音快捷键，才停止收音并进入最终校准。停顿、轻声和持续安静不会自动结束。
- 校准期间按 Enter 不预约写入；完成后核对预览，再按一次 Enter 才写入正文。长按 Enter 不会跨阶段连续触发。
- 浮层显示计时，单次上限从 60 秒延长到 10 分钟，最后 30 秒显示即将到时。达到上限只停止收音并保留草稿，仍需手动请求校准及确认写入。
- 麦克风持续安静改为提示；设备没有返回采样或连接中断仍报告故障。设置移除停顿时长选项，旧设置和备份字段兼容保留，不再影响收音。
- 设置页试用遵循同样流程，使用“开始 / 停止试用”和“确认试用文字”完成两步操作。

## 更新

解压到新目录，运行 `install.cmd`，保存工作后注销 Windows 并重新登录。新版新增“到上限，待校准”状态，DLL、引擎与模型 worker 必须一起升级；不要覆盖仍被应用加载的旧目录。保留旧版本及个人数据备份可供回滚。

自动回归、样本检查及未验证范围见 [验证记录](v0.2.0-rc.7-validation.md)。
