# v0.2.0-rc.9 验证记录

## 模型闲置释放

在原生 Windows 设置窗口复现了旧版的问题。取消勾选后重新打开设置，复选框恢复为开启，因为旧版只在启用模型时保存此项设置。

| 场景 | 回归断言 |
| --- | --- |
| 浏览其他模型、取消勾选后重开设置 | 配置保存了当前启用的模型和关闭的开关 |
| 重启引擎 | 从配置读取关闭状态 |
| 模拟已加载模型闲置五分钟 | 关闭时直接录音，开启时在下次录音前重新准备 |
| 配置文件被占用 | 显示保存失败，复选框恢复为原来的状态 |
| 模型下载中或切换已排队时修改开关 | 立即保存最新值，模型任务完成时沿用该值 |

下载回归等到设置写入磁盘并收到竞争激活请求后，才让下载夹具完成。闲置计时测试使用模拟时钟和隔离采音。
