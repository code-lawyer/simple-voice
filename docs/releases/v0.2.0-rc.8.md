# v0.2.0-rc.8 · 新版设置、键盘标点与手动停录

轻音输入法 Windows x64 发布候选。包含自 `v0.2.0-rc.6` 以来的本地更新。

## 新版设置

- 六页设置统一标题、字段和说明的字号。常用操作固定在底部，窄窗口改用顶部分类选择器。按 Alt 显示控件快捷键。
- 三套输入浮层皮肤可以在设置里即时预览，并在保存后应用。
- 词库读不到、麦克风断开或模型验证结束时，显示各自的状态。撤销删除会保留后来新增的同名词，快速改词后下次拼音组合即可读取新词表。

## 键盘标点

中文模式默认使用中文标点。单按 Shift 切中英文，按住 Shift 输入符号后仍处于原来的输入模式。写中文时，Ctrl + . 单独切换标点。把鼠标停在任务栏的「中」上可以查看当前选择。

| 主键盘按键 | 中文标点 | 英文直输 |
| --- | --- | --- |
| Shift + 减号 | —— | `_` |
| Shift + 6 | …… | `^` |
| Shift + 4 | ￥ | `$` |
| Tab 上方的反引号键 | · | 反引号 |
| Shift + 反引号键 | ～ | `~` |
| 反斜杠 | 、 | `\` |
| 逗号与句号键 | ，。 | `,.` |

输入 `nihao` 后直接按 Shift + 减号，可写入「你好——」。候选仍可用减号和等号翻页。刚打完数字时按句号键可继续输入小数，如 `3.14`。要写中文句号，可退格删掉小数点，再按一次句号键。

## 手动停录

录音中按 Enter 或再次按语音快捷键停录并校准。核对预览后，再按 Enter 写入。停顿和轻声时继续录音。单次上限为 10 分钟，到达上限时保留草稿，等待你请求校准。[手动停录的完整说明](https://github.com/code-lawyer/simple-voice/blob/v0.2.0-rc.8/docs/releases/v0.2.0-rc.7.md)

## 安装和升级

将完整 ZIP 解压到新目录，运行 `install.cmd`。首次安装会下载并校验运行时和模型。旧版用户保存工作后注销 Windows 再登录，让已打开应用重新加载输入法组件。配置与个人词库继续使用原用户目录。

本候选版未做 Authenticode 签名。真人麦克风、实际编辑器和跨屏场景仍待现场验收。[验证记录](v0.2.0-rc.8-validation.md)
