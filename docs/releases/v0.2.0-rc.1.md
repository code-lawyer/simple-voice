# v0.2.0-rc.1 · 输入能力与可靠性改进

这是 Windows x64 本地发布候选，尚未推送公开 Release，也未覆盖本机已注册版本。
真人麦克风和浏览器/Codex 验收按用户安排后置。

## 变化

- 移除无上下文同音替换与旧整句覆盖，保护数字、专名、英文大小写和标识符；格式整理遇到内容变化回退原文。
- 词库按基础数据、后台 Rime 偏好、显式个人词语分层。普通语音不再自动收词或保存新待学习整句。
- 新增词语搜索、分页、输入码编辑、删除与撤销；已有旧记录兼容保留、按365天未使用清理，不作为改写依据。
- 更新授权明确的中文/英语数据，提供简拼、有限错拼、英文补全和显式中英词组；修复 Shift/大小写、Enter 原文与组合内光标编辑。
- 本机横评后选择双语 Zipformer 草稿 + Qwen3-ASR 0.6B INT8 定稿，保留中文优先配置。长录音分段处理，避免整段尾部丢失。
- 待确认语音可编辑、复制、恢复识别原文；错误占位或失败定稿需要补全，不自动提交。
- 借鉴 Handy 的准备状态、设备选择、首帧采样、输入电平、故障提示和重试。模型加载与定稿不阻塞取消；迟到结果不会误上屏。
- 新增统一原生设置与使用引导，保留三套浮层皮肤。修复深色设置可读性、助记键、引导按钮误保存和搜索计数文案。
- 补齐固定数据/模型哈希、源码依赖哈希、Windows CI、独立包清单和两种模型自检。

## 迁移

个人目录和 TSF 技术标识保持不变；新增 preferences.ini 与 personal_terms 表。
旧自动词条不会自动冒充“我的词语”。既有Rime学习数据保留；关闭学习使用独立不学习方案，显式词语仍可使用。

请把新包解压到新目录，安装后注销再登录。回滚可注册旧目录，但旧程序会恢复旧版本的学习/改写行为；建议更新前备份个人目录。

## 限制

很短的英文数字仍可能漏识别；噪声中文数字并非Qwen始终最好，因此保留中文优先。
长句拼音仍有同音歧义，不提供任意英语拼写纠错或任意中英整句预测。个人词语当前用于键盘候选，不接入语音热词。
模型加载/推理任务取消后仍在后台收尾；关闭引擎会等待工作线程，没有独立进程硬超时恢复。
