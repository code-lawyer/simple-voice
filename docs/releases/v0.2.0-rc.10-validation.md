# rc.10 本机试用记录

2026-11-21，Windows x64，本地 CPU，默认 Qwen3-ASR。对照使用上一个本地构建，它已经支持切入预加载和冷启动收音。两版使用相同的双语流式模型、Qwen 权重及录音。冷启动指本次测试的模型进程尚未启动，磁盘可以已有系统缓存。

## 按键到看见草稿

以 16 kHz 单声道音频模拟麦克风，每 20 毫秒送一帧。使用真实引擎、模型进程及 Windows 浮层，从发出录音指令计时，轮询可见窗口中的正确文字。普通话使用「开放时间」的「开」，英语使用「Hello, world」的「HE」。两轮交替运行旧版和新版。

| 实际浮层 | 上一本地构建 | rc.10 |
| --- | ---: | ---: |
| 普通话，冷启动 | 3938、4238 ms | 1566、1573 ms |
| 普通话，已加载 | 1715、1709 ms | 1556、1573 ms |
| 英语，冷启动 | 3835、3937 ms | 745、676 ms |
| 英语，已加载 | 438、451 ms | 422、452 ms |

另以 20 段 FLEURS 普通话和 8 段中英项目录音在已加载模型上比较，按已送入的音频长度计时。28 段里 7 段更早出现草稿，21 段相同。两版都能保留正确首字的 22 段里，5 段提前 160 ms，17 段相同。28 段在停录前的最后一版草稿逐字相同。中途连续更新的间隔中位数仍为 320 ms。提前出现的字里有一例与参考首字不同，另有一例在后续草稿中修订。个人口音、麦克风、蓝牙采集及嘈杂环境的端到端延迟仍需实际试用。

## 模型进程内存

Windows 工作集是进程当时驻留的物理内存，专用提交量是为进程分配的私有内存，两者分别采样。下表每版的两轮依次识别 5.59 秒普通话和 1.65 秒英语并完成定稿，未启用闲置卸载。长段峰值取相同的 17 段回归序列，其中包含一段 60 秒录音。

| 模型进程 | 上一本地构建 | rc.10 |
| --- | ---: | ---: |
| 仅加载后工作集 | 1261–1263 MiB | 1261–1264 MiB |
| 两句定稿后工作集 | 1489–1490 MiB | 1281–1282 MiB |
| 两句定稿后专用提交量 | 1581–1582 MiB | 1279–1280 MiB |
| 两句识别期间工作集峰值 | 1714 MiB | 1621–1622 MiB |
| 含 60 秒录音的回归序列峰值 | 2385 MiB | 1764 MiB |

同一 rc.10 进程连续交替识别以上两句共 50 次。第 2、10、25、50 次定稿后的工作集依次为 1280.4、1281.3、1273.5、1281.2 MiB，50 次定稿均与预期一致。Qwen 常驻时仅加载权重及运行时就占约 1.23 GiB。关闭 CPU 内存池带来重新分配的开销。单独交替复测，普通话停录后的定稿计算从 737–788 ms 变为 777–1151 ms，英语从 432–435 ms 变为 433–725 ms。两轮数据反映本机波动。[sherpa-onnx CPU 会话配置实现](https://github.com/k2-fsa/sherpa-onnx/blob/v2.0.1/sherpa-onnx/csrc/session.cc)

## 回归与复测

- 单元、引擎、TSF、浮层及模型进程五组 CTest 全部通过。新增模型进程回归覆盖草稿先就绪、重复音频应答保留已有草稿，以及整套模型就绪前后的切换。
- 17 段中英文、数字、静音和长录音的 Qwen 最终输出与对照逐字相同。静音输出为空。这批录音中既有版本都会漏掉 0.36 秒的英语单词「nine」，准确率仍有改进空间。
- 模型尚在加载时提前停止 1.65 秒英语录音，冷、热两次各接收 26,400 个采样，最终均为「Hello, world.」。麦克风数据来自固定回放，实际用户桌面无需打开麦克风即可完成这项检查。
- 复测浮层可执行 `voiceime_engine_integration.exe <隔离数据目录> --draft-profile <16kHz 单声道 PCM16 文件> <包含首字的 UTF-8 文本文件>`，模型验证与系统回归分别使用 `voiceime_recognizer_smoke` 和 CTest。[浮层回放实现](../../tools/engine_integration.cpp)

## 本机安装

安装包通过文件清单和离线模型校验。新开的 Windows 输入窗口通过系统注册加载 rc.10 输入法 DLL，并连接同一安装目录中的 rc.10 主引擎。前台切入轻音时，运行中的 Qwen 模型由该引擎持有。独立实测中，从未启动的状态切入后，后台完成整套模型预载用时 3.96 秒，两处输入窗口共用一次加载。真实桌面的个人词库和设置文件通过升级前后校验。已经打开并加载旧 DLL 的应用在重新启动进程或重新登录后切换新版。[已安装版本检查](../../tools/installed_check.cpp)
