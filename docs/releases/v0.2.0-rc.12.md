# v0.2.0-rc.12 本机试用版

轻音沿用 rc.11 的连续口述草稿和 Qwen3-ASR 定稿。遇到有持续人声、首次识别为空的短录音，Qwen 会用不同的首尾静音重新识别。至少两次结果一致才把重试文字放进预览。长口述达到单段时限时，优先在一段连续安静区间中部切开。

要改善常用姓名、项目名或英文术语，在设置的词语页选中已保存词语，点击「加入语音专名」，在模型页核对后点击「启用所选模型」。也可以直接编辑模型页的专名列表，使用中文逗号、顿号或英文逗号分隔。下次使用 Qwen 时，提示参与模型解码，预览仍可编辑。

两个应用的拼音输入各自保留当前组合，由同一登录会话的轻音引擎统一管理原来的 Rime 学习库。在一个应用中反复选用的候选可在另一个应用的新组合中升位。暂停学习期间使用基础词表和手动保存的词语，恢复后可以继续使用此前的偏好。

升级时，如果旧应用还占用拼音学习库，新引擎会等文件锁释放后再接收拼音输入。语音可以继续使用。保存工作、注销 Windows 并重新登录，可让仍在运行的旧应用全部释放词库。
