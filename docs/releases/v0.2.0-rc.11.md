# v0.2.0-rc.11 · 连续口述本机试用版

连续说话时，轻音会根据三条共用同一份双语 Zipformer 权重的识别流，提前显示有上下文支持的短草稿。麦克风独立采集，识别暂时繁忙时仍按顺序保存已经收到的语音。已有安装可复用原来的模型文件。

定稿继续使用本地 Qwen3-ASR。检测到安静尾音时，轻音会在后台先算一次。短暂停顿后接着说会重新使用整句音频。较长口述遇到停顿，要等草稿识别到后面的新词，才会单独保留前段定稿。停顿后只有杂音时，Qwen 会用完整录音核对。按 Enter 或语音快捷键停录，看完预览，再按一次 Enter 写入。

这是 Windows x64 未签名本机候选构建。解压到独立的固定目录后运行 `install.cmd`。已打开的应用可能保留旧版输入服务，重新打开相应应用或重新登录 Windows 后会加载新版。升级沿用原来的快捷键、模型选择和词库。首次安装的语音快捷键为 Ctrl + Alt + Space。[本机回放、内存与验收记录](v0.2.0-rc.11-validation.md)
