# Simple Voice · 轻音输入法 v0.1.0 Preview

首个公开 Windows x64 预览版。

## 本次内容

- 统一产品名为 **Simple Voice / 轻音输入法**，系统输入法显示名、托盘提示与文件版本信息同步更新。
- Rime 全拼输入，空格、数字键和鼠标选词，Shift 切换中英文。
- 本地语音识别：停顿后校准，浮层先预览最终文本，再按 Enter 写入正文。
- 钛银、极昼、深空三套原生皮肤，候选条和语音框同步切换。
- 浮层稳定性、光标定位、写入确认、词库故障回退和 365 天语音记录清理。
- 提供安装、卸载、自检脚本；官方运行时和模型下载带 SHA-256 校验。
- 修复从任意工作目录启动时的字典定位，并保留旧版个人数据兼容性。

## 下载与安装

下载 `SimpleVoice-v0.1.0-windows-x64.zip`，完整解压到长期保留的目录，安装
Microsoft Visual C++ x64 运行库，然后双击 `install.cmd`。
首次下载官方依赖约 492 MiB，下载完成后可离线使用。
管理员授权完成后注销 Windows 再登录，使用 `Win + Space` 选择「轻音输入法」。

ZIP 附带 `.sha256` 校验文件和逐文件 `package-manifest.json`。
发布包不重新分发模型权重，来源和许可状态见 [第三方说明](../../THIRD_PARTY_NOTICES.md)。

## 验证与限制

预发布状态保留。发布前重新运行本项目四组 CTest，以及真实模型 WAV 样本检查；
安装包在独立解压目录准备依赖并加载模型自检。自动化测试不启用真人麦克风。
详细结果见 [发布验证记录](v0.1.0-validation.md)。

真人麦克风、浏览器/Codex 的完整输入流程、物理多屏和屏幕阅读器验收仍待完成。
仅提供 Windows x64 DLL，暂不支持 32 位应用、ARM64、macOS 或 Linux。
此版未做代码签名。
