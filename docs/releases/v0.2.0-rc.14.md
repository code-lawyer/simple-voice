# v0.2.0-rc.14 预发布版

本版修复了语音确认后焦点变化、拼音组合中断，以及七天词语审阅中的保存冲突。试用包面向 Windows Intel/AMD x64，使用说明见包内的 `START-HERE.txt`。[本机验收](v0.2.0-rc.14-validation.md)

- 在输入框按 Enter 确认后，如果焦点在实际写入前移走，轻音会保留预览，可在目标输入框重新确认。拼音组合期间引擎断连时，新版文本服务会保留已经输入的拼写。
- 「设置 → 我的词语 → 最近七天」支持跨页勾选。更正后的词与已有词条的输入码冲突时，整批选择都保留供修改。刷新仍停在正在看的词，保存其他词也会保留尚未勾选的编辑。勾选「这个词也用于语音识别」会将该词同时加入 Qwen3 专名。
- 长拼音候选会利用可用宽度显示词尾。长草稿更新会保留阅读位置。有可用定稿时，浮层同时显示识别文字和需核对的原因。
- 个人词表只在内容发生变化或同步需要重试时重新导出。已完成恢复但恢复记录暂时无法删除时，重启轻音仍可继续使用个人词库。

这是未签名的 Windows x64 预发布版。已注册版本升级后，保存工作并重启 Windows，轻音随后会重新启用个人拼音学习库。
