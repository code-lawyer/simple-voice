# v0.2.0-rc.2 验证记录

日期：2026-11-15。范围：rc.1 独立审查确认的五项缺陷，版本递增为 0.2.0-rc.2。生产修改在 build-professional 构建；自动测试使用隔离数据、模拟采音和真实 Windows TSF，不操作用户文档。

## 修复与回归

| 缺陷 | 修复 | 验证 |
|---|---|---|
| 拼音 Enter 丢失光标后文本 | 从 Rime 取完整原始输入，清除组合后原样提交 | nihao 左移、Home、删除、退格、End；真实 TSF 分别提交 nihao / niao；第二次 Enter 不重复 |
| 井号词条不成为候选 | 使用 Rime 官方 TSV 的 `# no comment` 指令 | #include、#@metadata、# no comment；真实 Rime 候选及重启后上屏 |
| 旧编辑器覆盖新录音 | 接受新请求即关闭旧窗口；保存回调校验录音轮次与排队状态 | 慢模型准备期间旧窗关闭，不能编辑占位或提交旧文本 |
| 编辑清除写入不确定提示 | 编辑保存不清除不确定状态；编辑器补充核对正文提醒 | 回执超时后原样保存、修改保存均保持提醒；只有再次明确确认才发送修改后的文本 |
| Tab 被困在预览正文 | 处理多行 EDIT 的 WM_NEXTDLGCTL | Tab 正向循环、Shift+Tab 反向、Ctrl+Enter 保存，三皮肤均通过 |
