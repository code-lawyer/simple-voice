# rc.13 本地试用说明

这版缩短连续听写短句时的定稿等待，增加了最近七天的词语审阅。按 Enter 停录，看到最终文字后仍可修改、取消或再次按 Enter 写入。[同机回放与验收](v0.2.0-rc.13-validation.md)

## 怎样审阅自己的用词

1. 打开「设置 → 我的词语 → 最近七天」，勾选「收集最近七天的候选词」。默认关闭，从下一次轻音实际写入的语音或拼音开始累计。
2. 选择「常用词」看重复使用的词。选择「待核对」看写入前改过、草稿与定稿有差异、或短录音经模型重试才得到的词。「全部候选」支持搜索和翻页，出现一次的名字也可以找。
3. 点一行看短例。可以修改字形、核对拼音输入码，也可以在短例中选中一段连续文字，再点击「用选区补词」。例如分开显示的「轻音」和「输入法」可以补为「轻音输入法」。
4. 勾选要保留的词，点击「加入拼音词库」。跨页或切换筛选会保留已勾选的词。某个词还想用作语音专名时，单独勾选「这个词也用于语音识别」。专名在下次使用 Qwen3 时生效，识别结果仍可核对。

词语、次数、来源、待核对原因与一条短例保存在本机。每次使用独立计时，七天前的次数会过期。候选收集可以暂停，也可清空。已确认的个人词语沿用原有的管理和备份方式。

## 短句定稿

在普通短句出现安静尾音时，Qwen3 可以先开始一轮校准。用户接着说，系统将后续语音纳入定稿。短句已形成连续中文草稿且专名提示为空时，模型可以提前填入中文语言标签。有英文草稿或显式专名提示时继续自动判断语言。速度会随句长、停顿、模型及电脑负载变化。

本包供 Windows x64 本地试用。解压到新的目录后使用包内安装说明。已注册版本升级后需要重启 Windows。
